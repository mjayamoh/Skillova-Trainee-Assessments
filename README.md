# Skillova Trainee Assessments

This repository contains my completed Skillova trainee assessments.

## Completed categories

### Category 4 – Grafana Dashboards

Created a Grafana dashboard using a seven-day CSV dataset. The dashboard contains a Page Views time-series panel and a Total Signups Stat panel.

### Category 5 – Data Analysis

Cleaned and analysed a synthetic dataset of 1,000 customer-support tickets using Python, Pandas and a Jupyter Notebook.

### Category 6 – AI Chatbots and Prompt Engineering

Built a Python application using the Groq API to generate concise professional workplace messages and validate output constraints.
